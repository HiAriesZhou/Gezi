# Reading with Gezi

在终端里，读得自在。

Open a document or read Markdown from a pipe.

```sh
ge README.md
cat notes.md | gezi
```

| Keys | In the reader |
| --- | --- |
| / + Enter | Search text |
| n / N | Next / previous match |
| o / Tab | Outline / switch panes |

Files are read-only. Editing is not yet available.
