02 / Reading

From your shell.
At your keyboard.

01

Open a Markdown file

Formatted headings, highlighted code, and tables.

ge README.md
02

Find text and headings

Search with / and Enter. Open the outline with o.

/ Enter · n N · o Tab
03

Read from a pipe

Send Markdown into Gezi from another command.

cat notes.md | gezi
03 / Installation

Install Gezi.

macOS Apple Silicon
Reading available today.
Editing is not yet available.

Run this command in your terminal.

curl -fsSL https://raw.githubusercontent.com/HiAriesZhou/Gezi/main/install.sh | sh

Installs gezi and ge to ~/.local/bin.
