# Published release context: 0.1.15

Basic native Mermaid previews now join the read-only Markdown reader in direct
Kaku. Press m to switch the first visible Mermaid block between preview and
source. Unsupported diagram types and detected rendering failures retain source. Some unsupported statements may be ignored. Native rendering differs
from the official Mermaid renderer.

Gezi supports macOS Apple Silicon. Inline graphics require direct Kaku with
Kitty graphics enabled. Files remain read-only; editing, saving and undo are
planned. The package is ad hoc signed, without notarization.

This launch preparation does not create a new application version. Main contains
subsequent documentation changes; do not describe them as a new released binary.
